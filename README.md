# Web Dev – MERN Stack Journey

A comprehensive repository documenting my hands-on journey of learning **Full-Stack Web Development** using the **MERN Stack**. This repository contains a collection of mini-projects, UI components, frontend applications, React practice projects, JavaScript implementations, and foundational web development exercises built while mastering modern web technologies.

Rather than focusing on a single application, this repository serves as a progressive learning archive where each project represents a practical implementation of concepts learned throughout my web development journey.

# Getting Started

## Clone the Repository

```bash
git clone https://github.com/KartikeyG-world/Web-dev.Mern-Stack.git
```

## Navigate to the Repository

```bash
cd Web-dev.Mern-Stack
```

Each project is self-contained and can be explored independently.

For static projects, simply open the corresponding `index.html` file in your browser.

For React projects:

```bash
cd <project-folder>
npm install
npm run dev
```
